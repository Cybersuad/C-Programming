# C Programming | Linux & Systems Programming

**Academic Project | PG3401 – C Programming | 2026**

## Overview

This repository contains my C programming project on Linux. 

The project consists of multiple programming tasks covering fundamental and advanced C programming concepts, including mathematical algorithms, modular programming, file handling, multithreading, inter-process communication, encryption and network programming.

The primary objective was to develop practical programming skills and gain a deeper understanding of how software interacts with operating systems, memory, files and networks.

## Technologies & Tools

- **Programming Language:** C
- **Operating System:** Linux
- **Compiler:** GCC
- **Build Automation:** GNU Make
- **Version Control:** Git & GitHub
- **Core Concepts:** Algorithms, File I/O, Threads, IPC, Encryption and Networking

## Project Structure

The project is organized into five main tasks.

### Task 2 – Mathematical Algorithms & Modular Programming

Implementation of mathematical algorithms using C.

Key concepts:

- Prime number identification
- Fibonacci sequences
- Perfect and abundant numbers
- Mathematical computations
- Functions and modular programming
- Header files and separate source files

### Task 3 – Structured C Programming

Development of a C application using multiple source files.

Key concepts:

- Modular program architecture
- Header files and function declarations
- Data processing
- Compilation and linking
- Build automation using Makefiles

### Task 4 – Multithreading, IPC & Encryption

Exploration of system-level programming concepts in C.

Key concepts:

- Multithreading
- Inter-process communication (IPC)
- Concurrent execution
- Prime number computations
- XTEA encryption
- File operations and data processing

### Task 5 – Network Programming

Implementation of network-related functionality in C.

Key concepts:

- Network communication
- Socket programming
- Network protocols
- Data transmission
- Error handling

### Task 6 – Data Reception & File Handling

Development of a C application involving data handling and file output.

Key concepts:

- Binary data processing
- File input/output
- Data reception
- Working with image files
- File integrity considerations

## Building & Running

The project was developed for a Linux environment.

Each task is stored in a separate directory and includes its own Makefile.

Example using Task 2:

```bash
cd task2_17
make
./task2
```

Other tasks can be compiled in their corresponding directories. Execution requirements and arguments may vary between programs.
